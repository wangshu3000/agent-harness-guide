# 十二大核心模块总览

> 综合 Anthropic、OpenAI、LangChain 以及全球 AI 工程社区的最佳实践，一个真正能落地的生产级 Agent Harness，需要由**十二个完全独立、环环相扣的核心模块**组成。少了任何一个，都无法支撑稳定的智能体运行。

## 模块的分层视角

按职责可以把十二个模块分成四组，便于记忆：

1. **运行骨架**（#1 编排循环、#12 初始化与终止）：决定智能体「怎么转起来、怎么停下来」；
2. **认知资源**（#3 记忆、#4 上下文管理、#5 提示词组装）：决定模型「每一轮能看到什么、记得什么」；
3. **行动能力**（#2 工具、#6 工具调用与结构化输出）：决定智能体「能做什么、怎么把意图变成调用」；
4. **稳定保障**（#7 状态检查点、#8 错误处理、#9 护栏、#10 验证反馈、#11 子 Agent 编排）：决定智能体「能不能扛住真实环境、值不值得信任」。

## 核心设计原则

- **环环相扣**：模块之间不是孤立的，例如「工具执行失败 → 错误处理 → 把错误包装成消息 → 回给编排循环 → 模型重新决策」是一条完整链路；
- **缺一不可**：缺上下文管理，长任务必崩；缺护栏，企业级不敢上线；缺验证，输出永远不可信；
- **独立可替换**：模块边界清晰，才能独立演进——换一个记忆实现、换一种验证方式，不影响其他模块。

## 阅读建议

- 第一次通读：按 1→12 顺序阅读，建立完整系统观；
- 聚焦排障：从「上下文管理 → 错误处理 → 状态检查点 → 验证反馈」四条线切入，这是生产环境最常见的故障点；
- 对照框架：读完十二模块后，再读《03-主流框架实践》，看五大框架如何落地这些模块。
