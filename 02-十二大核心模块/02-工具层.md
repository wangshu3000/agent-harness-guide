# 模块 2：工具（Tools）

## 一句话定位

**工具是智能体的手，是它与现实世界交互的唯一途径。** 如果说编排循环是智能体的心跳，那工具就是让心跳的每一次搏动产生实际作用的执行器。

## 工具的本质：不是随意函数调用，而是标准化 Schema

工具不是简单的函数调用，而是以**标准化 Schema** 形式定义的能力集合。一个工具 Schema 通常包含：

| Schema 字段 | 作用 |
| --- | --- |
| 工具名称 | 模型调用时的唯一标识 |
| 功能描述 | 告诉模型这个工具能做什么、什么时候用 |
| 参数类型 | 定义入参的结构与约束（JSON Schema） |
| 返回格式 | 定义执行结果的结构，便于模型读取 |

这些 Schema 会被**注入模型上下文**，让模型明确自己具备哪些操作能力——模型「知道」自己有什么工具可用，才能正确决策。

## 工具层的完整职责链

工具层的职责远不止「调用」这么简单，它是一条完整的流水线：

```
工具注册 → Schema校验 → 参数提取 → 沙箱执行 → 结果捕获 → 格式化观察信息 → 回传编排循环
```

| 环节 | 职责 | 为什么重要 |
| --- | --- | --- |
| **工具注册** | 把能力登记进 Harness 能力清单 | 只有注册过的工具才能被模型感知与调用 |
| **Schema 校验** | 校验模型生成的参数是否符合定义 | 防止模型传错参数、注入非法值 |
| **参数提取** | 从模型输出中结构化取出参数 | 模型输出可能含噪音，需精确提取 |
| **沙箱执行** | 在受控环境里运行工具 | 隔离副作用，防止越权与破坏 |
| **结果捕获** | 收集执行结果与错误 | 结果可能很大、可能失败，都要捕获 |
| **格式化观察信息** | 把结果转成模型能读懂的消息 | 模型只认文本/结构化消息，不是原始返回 |
| **回传编排循环** | 把观察信息交给下一轮推理 | 形成「行动→观察」闭环 |

## 为什么没有工具层，模型就只能「纸上谈兵」？

- 模型再强的推理能力，也只能输出文本；
- 没有工具层，推理结果无法变成「文件操作、命令执行、网页访问、数据查询」等真实动作；
- 工具层是模型意图与现实世界之间的**唯一桥梁**。

## 行业头部厂商的工具体系

### Anthropic Claude Code：六大类核心工具

| 类别 | 覆盖能力 |
| --- | --- |
| 文件操作 | 读、写、编辑、搜索文件 |
| 搜索 | grep/glob 等代码与文本检索 |
| 命令执行 | 在沙箱中运行 shell 命令 |
| 网页访问 | 抓取网页、解析内容 |
| 代码智能 | 语法分析、补全、重构辅助 |
| 子智能体孵化 | 创建子智能体执行独立任务 |

### OpenAI Agents SDK：三类工具

| 类型 | 说明 |
| --- | --- |
| **函数调用工具** | 开发者自定义的普通函数，注册后供模型调用 |
| **官方托管工具** | 平台内置能力：联网搜索、代码解释器、文件检索等 |
| **MCP 服务器工具** | 通过 Model Context Protocol 接入外部工具生态 |

> 补充理解 MCP：MCP（模型上下文协议）是 Anthropic 提出的开放标准，相当于「工具的 USB 接口」——只要工具实现了 MCP，任何支持 MCP 的智能体都能直接使用，解决了工具生态碎片化问题。

## 设计原则与思考

### 1. 工具不是越多越好

- 工具越多，模型的选择空间越大，出错概率越高（详见《07-工具范围》的架构抉择篇）；
- Vercel 砍掉 80% 的工具后性能反而提升；
- 原则：**只暴露当前步骤所需的最小工具集**。

### 2. 描述质量决定调用正确率

- 工具的功能描述是模型「学会使用工具」的唯一信息来源；
- 描述含糊 → 模型不知道该何时调用、怎么调用；
- 高质量描述应写清：用途、适用场景、参数含义、典型示例。

### 3. 执行必须带沙箱与权限

- 工具执行有真实副作用（写文件、删数据、发请求）；
- 沙箱隔离 + 权限检查是生产级 Harness 的底线（详见模块 9：护栏）。

### 4. 结果格式要「模型友好」

- 工具返回原始 JSON 未必适合模型阅读；
- 需要格式化为简洁、结构化的观察信息，降低模型理解成本、减少 token 消耗。

## 常见问题

### Q：模型幻觉出工具调用怎么办？

- Schema 校验兜底：不符合定义的一律拒绝；
- 护栏把关：高风险工具需用户确认；
- 错误处理：把失败信息回传给模型，让它重新决策。

### Q：工具执行结果太大怎么办？

- 观察屏蔽（Observation Masking）：只保留摘要与关键字段；
- 子智能体委派：让子智能体处理大结果，只回传精简摘要（详见模块 4）。
