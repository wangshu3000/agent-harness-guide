# 计算机架构类比：从 CPU 到操作系统

## 为什么用计算机架构来类比？

这是 AI 领域公认**最贴切**的解释方式。因为 Agent Harness 的每个组成，都能在经典计算机体系结构里找到一一对应的部件——理解这个类比，就理解了 Harness 的骨架。

## 完整映射表

| 计算机部件 | Harness 中的对应物 | 类比要点 |
| --- | --- | --- |
| **CPU**（裸处理器） | **裸大语言模型** | 只有核心计算能力，无法独立完成任何实际任务 |
| **内存（RAM）** | **上下文窗口** | 临时存储，速度快但容量有限，断电（会话结束）即失 |
| **硬盘** | **向量数据库与长期存储** | 容量大但响应较慢，用于跨会话持久保存 |
| **设备驱动** | **工具集成** | 让核心能调用外部能力（文件、网络、命令、服务） |
| **操作系统** | **Agent Harness** | 让所有部件协同工作、统一调度、兜底异常 |

## 逐项展开

### 1. 裸 LLM = 没有外设的 CPU

- CPU 再快，没有内存、硬盘、驱动，也只是个能算数的硅片，装不了操作系统、跑不了程序；
- 裸 LLM 再强，没有上下文管理、记忆、工具，也只是个能生成文本的模型，完不成实际任务。

### 2. 上下文窗口 = 临时内存

- 特点：**快**（直接塞进输入即可用）、**容量有限**（几千到百万 token，但总有用尽时）、**易失**（会话结束或超限就被丢弃/压缩）；
- 这就是为什么生产级 Harness 必须做上下文管理——就像操作系统必须管理内存，否则程序跑一会儿就「内存溢出」。

### 3. 向量数据库与长期存储 = 硬盘

- 特点：**容量大**（可存海量历史）、**响应慢**（需要检索、召回，而不是直接读取）；
- 承担跨会话的记忆持久化：任务进度、用户偏好、历史决策、知识库；
- 类比启发：好的系统不会把所有东西都常驻内存，而是「按需加载」——这正是 Harness 记忆分级设计的由来。

### 4. 工具集成 = 设备驱动

- 驱动让操作系统认识并使用硬件；工具让模型认识并使用外部能力；
- 没有驱动的操作系统控制不了打印机；没有工具的模型只能停留在文本输出，无法落地任何实际操作。

### 5. Agent Harness = 操作系统

- 操作系统的职责：进程调度、内存管理、设备管理、中断处理、安全隔离、崩溃兜底；
- Harness 的职责：编排循环（进程调度）、上下文管理（内存管理）、工具调度（设备管理）、错误处理（中断处理）、护栏（安全隔离）、状态检查点（崩溃恢复）。

## 重新发明冯·诺依曼架构

> 「我们通过 Agent Harness，重新发明了冯·诺依曼架构。」
> —— 贝伦·米利奇（Beren Millidge），2023 年《AI 的脚手架》

### 什么是冯·诺依曼架构？

经典冯·诺依曼架构的核心思想：**存储程序**——把指令和数据一起放在存储器里，由 CPU 不断执行「取指 → 译码 → 执行」的循环。它是现代计算机的通用蓝图。

### 为什么说「重新发明」？

- 经典架构把**计算**与**存储**分离，用总线连接；
- Agent 系统把**模型推理（计算）**与**记忆/上下文（存储）**分离，用 Harness 连接；
- 编排循环的「组装输入 → 模型推理 → 执行工具 → 回填观察」本质上就是「取指 → 执行 → 写回」的智能体版；
- 记忆系统就是「存储程序」的语义版——历史经验以提示词的形式参与下一轮计算。

### 为什么这是「必然抽象」而非简单封装？

- 人类计算机几十年的演进证明：只要存在「通用计算单元 + 可分离的存储 + 外部设备」，就必须有一层系统软件做协调；
- AI 智能体走向实用，同样无法绕过这层协调逻辑；
- 因此 Harness 不是某家公司的发明，而是**计算系统发展的一种必然抽象**——是任何 AI 智能体在走向实用过程中都绕不开的底层逻辑。

## 类比能带来的设计启发

1. **分层管理**：像操作系统分「常驻内核 + 按需加载模块」一样，记忆也要分「常驻 + 按需」；
2. **资源是稀缺的**：内存（上下文）要省着用，该释放就释放（压缩），该换入就换入（检索）；
3. **驱动要标准化**：设备驱动有统一接口（如 USB），工具也要有统一 Schema，否则 OS 无法管理；
4. **系统要能兜底**：没有操作系统会假设程序不崩溃，Harness 也不该假设模型不出错。

## 小结

| 一句话 | 含义 |
| --- | --- |
| 模型是 CPU | 核心算力，但孤掌难鸣 |
| Harness 是操作系统 | 让所有部件协同、调度、兜底 |
| 智能体 = 操作系统 + CPU + 外设 | 缺一不可，而 Harness 是那个「缺了就不转」的部分 |
